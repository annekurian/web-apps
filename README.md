# Web Apps

A playground for building small web applications to learn different languages, frameworks and tools approah. Each folder is a self-contained project that can be run on its own. Most of them rebuild the same idea in a different stack, so the differences are easy to see side by side.

These are learning projects, so the focus is on understanding concepts such as routing, templating, database access and sessions rather than on production polish.

| Project                                          | Language             | Framework | Templates | Port |
| ------------------------------------------------ | -------------------- | --------- | --------- | ---- |

| [`python-flask-sqlite3`](./python-flask-sqlite3) | Python               | Flask     | Jinja2    | 5000 |
